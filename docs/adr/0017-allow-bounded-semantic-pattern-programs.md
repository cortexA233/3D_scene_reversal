# Allow bounded semantic pattern programs

Hero patterned objects may reproduce authored visual identity with a Bounded Semantic Pattern Program that maps semantic surface coordinates to appearance through analytic motifs, compact vector controls, layering, symmetry, repetition, and domain transforms. This remains inside the Code-only Production Runtime only while every object-specific control counts against the existing scalar and bundle budgets, representation size is independent of texture and sampling resolution, and no texture, pixel table, sampled grid, vectorized bitmap, or sampled appearance hidden in shader constants crosses the production boundary.
