# Gate Stage 2 on Stage 1.5 evidence

Stage 2 remains a formal Single Mesh Lab exit path rather than an exploratory continuation of the frozen two-of-four Stage 1 result. Bamboo Shoot and Mushroom implementation may begin only after Stage 1.5 has corrected and rerun the complete-source Object-specific Scalar audit for every Stage 1 object; produced a second compact Stone representation that passes the complete frozen v1 geometry, appearance, nonvisual, and browser gates; produced a passing Code-only Umbrella hero-pattern representation under an accepted pre-implementation Patterned Appearance Baseline and the existing nonvisual budgets; obtained native Firefox and Safari GPU visual-tolerance evidence for every otherwise-qualified candidate; and frozen pre-implementation Quality Baselines for both Stage 2 objects. If either failed Stage 1 class cannot satisfy its accepted boundary, the project revisits the full-island North Star instead of relabeling further evidence gathering as Stage 2.

Stage 2 then runs strictly in order: Bamboo Shoot must pass every applicable visual, nonvisual, determinism, Reference Independence, and Native GPU Visual Gate before Mushroom fitting begins. Either object may attempt a second pre-justified compact representation after its first fails, but two failed reasonable representations stop Stage 2 for a representation and boundary review rather than allowing the next object or a formal exit claim.

This strict gating corrects a Stage 1 process deviation: the accepted experiment specification required each tracer bullet to pass before the next began, but Vase and Umbrella proceeded after Stone resolved with a negative result. The extra evidence remains valid, while the postmortem records that a resolved negative ticket is not a passing stage gate and later stages may not repeat that semantic drift.

Stage 1.5 itself uses early kill gates: first complete the postmortem, repair and rerun complete-source scalar auditing, and qualify the native Firefox/Safari harness with the already-accepted Stone Path and Vase; next require Stone's 24-direction representation to full-pass v1 and every shared gate; only then calibrate patterned-appearance v2 and require the geometry-frozen Umbrella candidate to pass; only after both recoveries pass are the separate Bamboo Shoot and Mushroom Calibration Brackets frozen together. A final Stage 1.5 certification authorizes Stage 2 only when every preceding gate is green.
