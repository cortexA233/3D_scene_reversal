# Allow reference source guidance without production dependency

The development-side Scene Reconstruction Module may read the reference application's source code as Reference Source Evidence to explain transforms and semantics, fit parameters, and identify reusable procedural algorithms. A general algorithm or compact resolution-independent semantic parameter may enter production only by being explicitly promoted into an independently owned and audited Scene Generation Module that contains no reference paths, loaders, source-node identifiers, dense geometry or appearance samples, evaluation logic, or build-time source inspection; the replacement-only build must still succeed with the entire reference implementation unavailable, and the Assembled Authored Scene remains authoritative when source intent and rendered reality disagree.
