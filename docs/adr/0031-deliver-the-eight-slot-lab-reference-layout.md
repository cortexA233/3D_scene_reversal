# Deliver the eight-slot Lab reference layout

The integrated Single Mesh Lab product reproduces the fixed spatial arrangement,
normalized display scale, orientation, and shared viewing context of the eight-object
Lab reference scene. Each stage fills only the corresponding slots for available
Procedural Replacements; unfinished slots stay empty instead of loading Authored
References. Island-village source-world assembly and per-object delivery routes are
rejected because the requested composition target is the eight-slot Lab layout and
the delivery must remain Code-only.
