# Deliver one reference-layout scene

The final product is one integrated Reference-layout Delivery, not one scene or
route per reconstructed object. Every accepted Procedural Replacement must be
assembled into the shared world at the position, orientation, scale, and
spatial relationship corresponding to the Authored Reference. Single Mesh Lab,
gallery, replacement, and Evaluation Harness pages remain development-only
surfaces and cannot be promoted as the final deliverable. The integrated layout
must still satisfy the Code-only Production Runtime: placement is retained as
compact semantic scene data, without loading or copying Authored Reference
assets at runtime.
