# Use a bounded semantic terrain program

The Procedural Replacement describes the island with a Bounded Semantic Terrain Program: a closed coastline assembled from semantically located curve controls, a fixed-cap composition of named analytic plateau, ridge, hill, channel, dune, and shore-shelf features, and versioned deterministic noise. Development fitting may read the complete reference heightfield, but the Production Runtime may retain neither a height grid nor per-vertex heights, regular samples, distance fields, or source-resolution data; mesh tessellation remains a general generator concern independent of the recipe, and the semantic control budget is frozen before candidate fitting rather than expanded until it approximates a disguised heightfield.
