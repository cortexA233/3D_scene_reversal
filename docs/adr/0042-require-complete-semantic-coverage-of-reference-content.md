# Require complete semantic coverage of reference content

Scene Parity Foundation produces a Semantic Coverage Manifest in which every renderable reference geometry, light, and visible environment layer is classified as an identity-bearing entity, distributed cover, terrain/coast/ocean, horizon content, or an explicitly justified non-target. Unclassified visible content is blocking, and coverage is reported by entity count, world surface area, and Normative Scene Capture pixels so hard-coded name filters, many tiny objects, or one dominant terrain surface cannot hide omissions; classification enters the development plan, while source-node inventories remain outside the Production Runtime.
