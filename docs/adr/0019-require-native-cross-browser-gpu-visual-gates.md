# Require native cross-browser GPU visual gates

An otherwise-qualified Procedural Replacement must pass its accepted Quality Baseline from fresh Authored Reference and replacement captures produced inside hardware-accelerated Firefox and Safari, using the same twelve-view full-pass protocol and at least two stable capture runs per browser. Evidence records the browser, OS, Three.js, GPU and WebGL renderer, color configuration, and acceleration state; software renderers and browser-engine shells are rejected, while existing JavaScriptCore and SpiderMonkey structure and bounds signatures remain complementary CPU evidence rather than substitutes for a Native GPU Visual Gate.
