# Gate Stage 2 on Stage 1.5 evidence

Stage 2 remains a formal Single Mesh Lab exit path rather than an exploratory continuation of the frozen two-of-four Stage 1 result. Bamboo Shoot and Mushroom implementation may begin only after the Stage 1.5 Decision Gate has produced a passing second compact Stone representation, a passing Code-only Umbrella hero-pattern representation under an accepted pre-implementation Patterned Appearance Baseline and the existing nonvisual budgets, native Firefox and Safari GPU visual-tolerance evidence for every otherwise-qualified candidate, and frozen pre-implementation Quality Baselines for both Stage 2 objects; if either failed Stage 1 class cannot satisfy its accepted boundary, the project revisits the full-island North Star instead of relabeling further evidence gathering as Stage 2.

Stage 2 then runs strictly in order: Bamboo Shoot must pass every applicable visual, nonvisual, determinism, Reference Independence, and Native GPU Visual Gate before Mushroom fitting begins. Either object may attempt a second pre-justified compact representation after its first fails, but two failed reasonable representations stop Stage 2 for a representation and boundary review rather than allowing the next object or a formal exit claim.
