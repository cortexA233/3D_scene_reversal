# Allow a versioned-category Single Mesh Lab exit

The Single Mesh Lab may formally exit when six of eight required references, including Bamboo Shoot and Mushroom, pass their individually declared and frozen Category-specific Quality Baselines plus every shared nonvisual and Native GPU gate. The exit report must list each object's baseline version and state `PASS under versioned category-specific baselines`; it may not collapse mixed baselines into one score or rewrite the historical `single-mesh-quality-baseline-v1` Stage 1 result from two-of-four failure into a retroactive four-of-four pass.
