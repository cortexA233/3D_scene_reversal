# Retain only resolution-independent semantic measurements

The Code-only Production Runtime may retain Semantic Measurements such as dimensions, compact footprints and profiles, symmetry and repetition parameters, deformation controls, semantic anchors, material scalars, and small palettes. It may not retain data whose size follows authored vertex, triangle, texture, pass, or sampling resolution, including decoded mesh attributes, dense cross-sections, surface samples, extracted pixels, or render passes. Original world placement may later belong to scene layout but not to an Object Generator, while source-node identifiers, Lab slots, and display normalization remain development-only metadata. Per-recipe parameter and byte budgets will be calibrated by the Stone Path pilot without weakening this resolution-independence rule.
