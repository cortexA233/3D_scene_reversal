# Require all eight Lab objects for formal exit

The earlier six-object exit deferred Blue Hat and Candle and no longer matches
the requested final product. A Versioned Category Exit now requires Stone Path,
Stone, Bamboo Shoot, Blue Hat, Vase, Candle, Mushroom, and Umbrella to populate
their fixed Eight-slot Lab Reference Layout positions and pass their declared
category baselines and shared gates. Staged previews may leave unfinished slots
empty, but the final integrated delivery and exit report must be 8/8; this does
not authorize full-island reconstruction or full-island tickets.
