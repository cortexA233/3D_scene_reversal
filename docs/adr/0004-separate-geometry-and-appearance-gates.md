# Define exact-ish reconstruction with separate geometry and appearance gates

Object-level Exact-ish Reconstruction is evaluated as multi-view observational equivalence rather than source-topology identity or single-screenshot resemblance. Each Procedural Replacement must first pass a Geometry Gate in which reference and replacement use the same neutral evaluation material, transform, cameras, and lighting and are compared by bounds, silhouette, depth, and world-normal evidence. Only then is it evaluated through an Appearance Gate comparing the Authored Reference material with the procedural material by RGB, palette, and perceptual evidence. Objects whose authored textures carry visible identity must ultimately pass both gates, but appearance cannot compensate for geometry failure.
