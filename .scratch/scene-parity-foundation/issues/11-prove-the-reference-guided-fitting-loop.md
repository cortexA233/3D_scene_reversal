# 11 — Prove the Reference-guided Fitting Loop

**What to build:** Demonstrate one complete, controlled reconstruction iteration in which direct read-only reference evidence produces a compact persisted correction, the real production path regenerates the candidate, and the frozen acceptance evidence improves without transient adapter fixes or unrelated random drift.

**Blocked by:** 05 — Compare semantic layout and direct surfaces; 10 — Calibrate and freeze Scene Quality Baseline v1.

**Status:** ready-for-agent

- [ ] Add one non-interactive fitting-loop check that starts with a declared, measurable Recipe error and remains red until a persisted production-safe correction is regenerated and observed.
- [ ] Select one narrow identity-bearing layout or geometry tracer whose reference measurement, candidate discrepancy, and permitted compact parameter correction are unambiguous.
- [ ] Read the complete required reference geometry and source evidence through strictly read-only Reference Access.
- [ ] Measure the initial error with the same metric implementation used by frozen Scene Acceptance.
- [ ] Persist the correction into the Scene Recipe or independent production generator implementation, never into the Candidate Adapter or acceptance artifacts.
- [ ] Regenerate through the replacement-only Scene Generation path and prove the intended structural or geometry metric improves under the frozen baseline.
- [ ] Prove the reference pre/post summaries and frozen threshold content remain unchanged.
- [ ] Prove unrelated entities retain identical derived seeds, semantic structure, and deterministic CPU geometry.
- [ ] Reject a control implementation that applies the same correction only during evaluation or serializes dense reference evidence.
- [ ] Emit a fitting-history record that names the measured discrepancy and compact production change without retaining source meshes, samples, or pixels.
- [ ] Re-run read-only Scene Acceptance from a clean generation and prove it observes the persisted result without continuing to fit.
- [ ] Keep the tracer narrow; this ticket proves the loop and does not tune the whole island.
